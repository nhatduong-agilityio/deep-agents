# /ddr

You are creating a new Design Decision Record for: **$ARGUMENTS**

1. Read `docs/decisions/README.md` to find the next available DDR number.
2. Read `docs/decisions/TEMPLATE.md` for the required format.
3. Based on the current conversation context, draft Context, at least 2 Options

   Consequences. If there isn't enough information to fill any section
   meaningfully, STOP and ask — do not fabricate options or a rationale.
4. Write the file to `docs/decisions/DDR-{number}-{slug}.md`.
5. Add a row to the table in `docs/decisions/README.md`.
6. Confirm the file path to the user. Do not proceed to implement anything based
   on this DDR unless explicitly asked.
